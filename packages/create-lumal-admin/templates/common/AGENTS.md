# 项目开发指令

先阅读 [开发约定](docs/DEVELOPMENT.md)，再修改代码。

- 使用 Vue 3、Composition API、`<script setup lang="ts">` 和明确的 TypeScript 类型。
- 组合式逻辑按 `/***********************说明*********************/` 分块，模板引用使用 `useTemplateRef`。
- 只使用依赖包的公开 API，不导入 Lumal Monorepo 私有源码。
- 组件负责呈现，Composable 负责复用状态与生命周期，API Adapter 负责后端字段转换。
- 路由负责页面装配，Store 只保存跨页面状态；业务规则留在业务模块。
- 前端认证、菜单和按钮权限不能替代服务端鉴权。
- 新增页面、修改接口或公共行为时补充对应测试，禁止将接口失败伪装成演示成功。
- 不添加未使用的重依赖，不批量改写无关文件，不提交凭据、私有数据或构建产物。
- 完成前执行 `pnpm check`，分别报告通过、失败和未执行的检查。
